## 显示端根因与改动

原控件缓存的是最后一次单槽事件。其他布局首次创建时，用 NULL event 初始化为
slot 0 / disconnected / battery 0，未重建已经连接的两个槽；连续事件合并到一个
显示 work 时，也可能仅留下最后一个槽位。Operator 的初次更新还发生在控件加入
更新列表之前。因此切换外观不能可靠继承已经存在的外设状态。

T5-02 从共享连接观察器和 ZMK 电量缓存读取两个槽的完整快照；创建布局和更新
布局走同一路径，刷新覆盖全部槽位。连接状态在发布事件前原子更新，忽略未跟踪
连接的断开事件。Operator 先注册控件再做初次刷新。

物理左右不由蓝牙槽号自动定义。本次按用户报告的当前绑定顺序，设置
`CONFIG_PROSPECTOR_LEFT_PERIPHERAL_SLOT=1`：左图示用 slot 1，右图示用 slot 0。
这只改变 UI 顺序；设备页 K1/K2 仍为原始槽号。正常重启不改变此配置；若以后重新
配对导致槽号顺序变化，需要重新核对这个设置，不应通过清除配对来纠正 UI。

键位和轨迹球处理链路未因本次显示修复改变，左外设继续使用当前正常固件。

## T5-02 后续：产品 ID 0xFF 与用户 PCB 核对

用户刷入原诊断版后报告：step 2 读取产品 ID 为 `0xFF`，预期 `0x3E`，初始化失败；
之后活动切换时 PERFORMANCE 也始终读到 `0xFF`。芯片尚未初始化，不能通过移动
信用卡、调整光学距离或检查 BLE 鼠标转发解决这个阶段的问题。活动日志里的
`Performance mode ... complete` 只表示 SPI API 返回成功，不证明芯片接收了命令。
`Failed to start advertising (-120)` 中 120 是当前 Zephyr 的 EALREADY；用户仍可连接并
打字，不能据此清除绑定，也不能用它解释传感器的产品 ID 错误。

用户已确认：Breakout 与 Holder 的六线连通，二者输入供电为 3.3V；PMW3610 芯片
第 14 脚与两个电容的一端连通，对地约 1.79V。该脚是 VDD，而不是 MCU 的 D14。
[用户提供的 PixArt 数据手册](https://www.epsglobal.com/Media-Library/EPSGlobal/Products/files/pixart/PMW3610DM-SUDU.pdf?ext=.pdf)
第 2、6、8 页分别确认引脚、VDD 允许范围 1.7–2.1V、产品 ID 0x3E。
**1.79V 在范围内，不能据此认定欠压或把这个脚改接 3.3V。** 万用表静态读数不能排除
启动时的瞬态供电问题。BOM 的 U1 为 TCR2EF19，网络名是 `+1V9`；实测数值较该名义值
低，但仍在传感器规格内，尚无证据证明 LDO 损坏。

已读取用户工作区的制造文件（不是仅凭丝印猜测）：

- `pcb/01 - PMW3610 Breakout/netlist.ipc`：J1 与 U2 芯片脚的完整网络。
- `pcb/02 - Nano Holder/adapter-F_Cu.gbr` 和 `adapter-B_Cu.gbr`：Gerber X2 的
  `%TO.P` 元件焊盘、`%TO.N` 网络属性；右主控 U2，右侧接口 J8。
- `zmk/app/module/boards/nicekeyboards/nice_nano/arduino_pro_micro_pins.dtsi`：
  将 Pro Micro 的 TX/D1、RX/D0、SDA/D2、SCL/D3 位置转换成 nRF GPIO。

| 信号 | Holder 右侧路径 | nRF52840 | Breakout / PMW3610 |
|---|---|---|---|
| Motion（接口标 MISO） | J8.5 `miso_r` → U2.1 TX/D1 | P0.06 | J1.5 → 芯片 8 |
| SCLK | J8.4 `sc_r` → U2.2 RX/D0 | P0.08 | J1.4 → 芯片 3 |
| SDIO（接口标 MOSI） | J8.3 `mosi_r` → U2.5（D2 位置） | P0.17 | J1.3 → 芯片 2 |
| NCS（接口标 CS） | J8.2 `ss_r` → U2.6（D3 位置） | P0.20 | J1.2 → 芯片 5 |
| 供电 | J8.1 `+5V` → U2.21 VCC | 用户实测 3.3V | J1.1 → 芯片 6 VDDIO / LDO 输入 |
| GND | J8.6 GND | GND | J1.6 → 芯片 11 |

`+5V` 是旧 Pro Micro 设计的网络名称，不是要求输入 5V。
Gerber 的 U2.5/6 功能名写成 SCL/SDA；这里按 Pro Micro 焊盘位置和 nice!nano
映射取 GPIO，不把该功能名当成实际启用 I²C 的证据。
当前固件的 SCLK=P0.08、SDIO=P0.17、NCS=P0.20、IRQ=P0.06 与这些文件一致。
此前“上游示例引脚可能不适配 Holder”的疑点，现已通过 PCB 文件排除；
不要改到 Pro Micro 常规 SPI 的 D14/15/16。此处 MISO 实际接 Motion，传感器数据由
单线 SDIO 传输；固件中的 MOSI/MISO 同 GPIO 是该驱动的三线 SPI 配置。
制造文件说明设计连接；实际焊接、插座接触与芯片引脚焊点仍需必要时实测。

### 用户后续实测：延时无效，NRESET 接近 0V

用户确认已刷入 delay1s 并重新断电上电；step 0 在 1.370s 执行，说明延时生效，
但 step 2 仍读到产品 ID 0xFF，初始化失败。该实验未修复问题，不继续盲目增加延时。
用户以芯片 11 脚为 GND，测得 6 脚 VDDIO=3.3V，7 脚 NRESET≈0V。

数据手册规定 NRESET 为低有效。若脚号正确、使用普通高输入阻抗直流电压档且读数
持续接近 0V，则芯片未退出硬件复位，可解释无法读到产品 ID；仍须通过复位网络
测量确认原因，不能直接判定芯片损坏。R1 的设计阻值达 2MΩ，低输入阻抗（LoZ）
测量会加载这个节点，需排除测量本身拉低电压的情况。

本地 IPC 和 B.Cu X2 网络再次核对：

```text
VCC（用户实测 3.3V）── R1（BOM 2MΩ）── PMW3610 第 7 脚 NRESET
```

R1.2 接 VCC，R1.1 接芯片 7 脚；这个复位网络没有引出到六针接口或 MCU。
现有驱动用 SPI 软件复位，不能通过 GPIO 释放该板的 NRESET。因此此时优先排查
R1 是否装配、焊点/走线、复位节点是否对地低阻；不改 GPIO、不清配对、不再构建
无依据的固件变体。BOM 的标称值不代表实物一定已装或阻值正确。

下一步用户测量：

1. 断开 USB 和电池，确认 PCB 背面 R1 是否有元件及焊接状态。
2. 断电电阻档，记录芯片 7–11 脚之间的稳定电阻；检查 R1.1 到芯片 7、R1.2 到

   若一路 3.3V、另一路约 0V，继续定位上拉开路/阻值或复位端漏电、短接。

本次没有进行硬件改焊；不建议将 NRESET 直接短接 VCC。是否补焊/更换上拉
电阻应在以上测量后决定。轨迹球验收保持 FAIL / 原因待定位；BLE 按键能工作

### R1 定位与 KM601 测量指导

用户进一步报告：疑似 R1 在板读数 1.144MΩ，芯片 7–11 脚电阻从约 1.5MΩ 上升到
2.3MΩ；仪表为 KAIWEETS KM601，先前的电压测量模式尚未确认。上述电阻读数没有
显示明显低阻短路；在板测量受其他支路、电容充电等影响，不能据此判断 R1 的
独立阻值或认定损坏。先在确认的手动 DC 电压模式下复测 NRESET，再判断复位状态。

R1 位于 bottom 面，中心坐标 (74.36, -102.97) mm；靠近芯片 7/8 脚，旁边是 C7。
局部定位图输出到本地 `build/reports/pmw3610-r1-location.png`，按背面视角镜像，
六针接口在左、GND 在接口上端、VCC 在下端。图中 A=R1.1=NRESET，B=R1.2=VCC。
这是按制造坐标绘制的示意，未依据实物照片确认装配。

[KM601 原厂说明书（2021，PDF 第 16 页）](https://m.media-amazon.com/images/I/A19qAjoM1gL.pdf#page=16)：
黑表线插 COM，红表线插 V/Ω 功能孔；短按 AUTO/FUNC 切到手动 V 档，确认 DC 和 V
标志；若为 AC，短按 SEL 切换。不需要选择电流孔或电流档，量程可自动。
测量电压时 PCB 需供电；黑表笔固定接已确认 GND，红表笔依次接 R1 的两个金属端，
分别记录 A–GND 与 B–GND 的电压。它们不是把两支表笔分别跨在 R1 两端的同一次测量。
先用相同档位确认第 6 脚/VCC 对地约 3.3V，以检查设置和接触，再测 A/B。

后续用户测量：Breakout GND–VCC=3.3V，R1 B 对地间歇出现 3.3V，随后约 0V/
0.004V；A 最高约 0.2–0.3V。不能把这些最高值当作稳定工作电压，也不能据此宣布
芯片损坏或直接更换 R1。B 与 VCC 在制造文件上是同一网络，应有一致电压；
优先区分探针接触、测点/档位、焊接/走线与实际供电中断。此前 VCC=3.3V 是单次
读数，不等于已证实连续稳定。

下一项测试改为断电后的 **B–VCC 连通性**，而不是继续重复 B–GND 电压：
拔 USB 并断开/关闭电池后，使用蜂鸣/低阻档；先碰两表笔记录基线，再将一笔放
Breakout VCC 焊点，另一笔放 R1 B 端金属端。预期接近表笔基线且稳定；若 OL、
高阻或间歇，需核对元件定位和焊点/走线。此处测量的是同一网络，不是跨过 R1，
不应测到 MΩ。另需实物背面近照与 KM601 档位/单位显示，以核对示意与实际操作。

用户随后确认：断电后 Breakout VCC–R1 B 持续蜂鸣，稳定约 0.1Ω。这支持 B 端到
