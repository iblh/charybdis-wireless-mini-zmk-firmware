### 用户新提供的机械测量

用户估计球最底端到透镜顶部约 3mm；此前约 1.5mm 时不响应。
重新渲染核对 LM18-LSI 原厂文档第 2 页 Figure 2 / Mechanical Assembly Requirements：
目标表面至 **Lens Reference Plane 的 A** 为 2.2–2.6mm、典型 2.40mm。
测量点必须对应图中基准面，不能用镜片凸起最高点、芯片外壳或 PCB 替代。
若 3mm 确为 A，则超过上限约 0.4mm；1.5mm 则低于下限 0.7mm，不能因后者失败排除距离影响。

按窗口均值加权约 148.5（窗口均值已向下取整，并非精确原样本均值），快门 35–67。
没有在已捕获样本中看到 SQUAL 归零，但传感器不触发时未必有样本，不能据此认证焦距正确。
因此光学距离与 BLE 节奏可以同时存在；单凭 3mm 或 SQUAL 均不能把所有卡顿归因于光学。
